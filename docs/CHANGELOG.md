# Changelog for NXP Over-The-Air-Programming Tool

## 1.5.0 - 2025-09-02

- Added support for MCXW23 for Bluetooth Low Energy communication protocol.  
- Migrated from PDF documentation to Github-hosted documentation in markdown files.  
- Bug fixes

## 1.4.1 - 2025-04-29

- Added OTAP Zigbee support for FRDM-MCXW72 and MCXW72-EVK for converting an *.axf or *.elf file into an *.ota file.  
- Added support in OTAP CLI for over-the-air transfers using Bluetooth LE.  
- Edited Security Keys window.

## 1.4.0 - 2024-11-22

- Added Bluetooth Low Energy and Matter support for and OTAP Matter support for KW47-EVK, KW47-LOC, FRDM-MCXW72, and MCXW72-EVK for secured *.sb3 files.  

## 1.3.0 - 2024-09-20

- Added Matter, Bluetooth Low Energy, Zigbee support for FRDM-MCXW71.  
- Bug fixes.  
- Updated GUI to the latest NXP Branding Guidelines.  

## 1.2.0 - 2023-12-11

- Added ZigBee support for K32W148-EVK regarding .ota file creation from an *.axf file and over-the-air transfer.  
- Added a sign command in OTAP CLI with *.hex and *.bin files support. Revised the demo steps.

## 1.1.2 - 2023-06-16

- Added a feature for saving, loading, and restoring the default configuration of a *.json file.  
- Extended the custom internal flash size support.  
- Fixed various bugs.  

## 1.1.1 - 2023-04-10

- Added a feature to enable creation of a custom size sb3 file for the internal flash.  

## 1.1.0 - 2023-03-06

- Added OTAP CLI and Matter support for sb3 creation.

## 1.0.6 - 2022-11-23

- Added a feature to edit the Commands field in the sb3 json configuration window for KW45B41Z-EVK, K32W148-EVK support, and bug fixes.  

## 1.0.5 - 2022-10-12

- Updated SPSDK to v1.8.  
- Bug fixes.

## 1.0.4 - 2022-08-24

- Added support for the external flash usage for KW45B41Z-EVK.

## 1.0.3 - 2022-06-02 

- Updated SPSDK and fixed bugs in the filtering section.

## 1.0.2 2022-04-18 

- Added json configuration windows, integrated SPSDK, and added support for.s19 files.

## 1.0.1 2022-03-04

- Added support for KW45B41Z-EVK.

## 1.0.0 2021-12-01

- Initial Release.
