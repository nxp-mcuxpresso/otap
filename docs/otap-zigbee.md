# OTAP Zigbee

For the Zigbee protocol, the following two approaches are available:

1. [Take an `.ota` file and send it directly over-the-air](/docs/zigbee-ota-file-transfer.md).
2. [Take an `.axf`/`.elf` file and create a custom `.ota` file to be sent over-the-air](/docs/zigbee-create-ota-from-axf.md).
